# 🌦️ Live Weather Dashboard

An interactive Python application that provides **real-time weather updates**, **UV index**, **wind chill**, and **map visualization** for any location worldwide.  
Built for users who want quick, beautiful, and accurate weather insights!

---

## 🛠️ Technologies Used
- **Python 3**
- **OpenWeatherMap API** - Weather data source
- **Folium** - Interactive maps
- **Plotly** / **Matplotlib** - Graphs and visualizations
- **Seaborn** - Statistical plotting
- **Requests** - API integration
- **dotenv** (optional) - Environment variable management

---

## ✨ Key Features
- 🌡️ View current temperature, humidity, pressure, and wind speed
- 🧴 Check UV index and feel-like temperatures (Wind Chill)
- 🗺️ See your city pinned on an interactive map
- 📈 Visualize forecasts and weather patterns
- 🔄 Update weather for multiple cities easily
- 🖥️ Clean, minimal interface with powerful back-end
